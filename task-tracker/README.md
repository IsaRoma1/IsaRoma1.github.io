# Вход в личный трекер «Фокус»

Адрес: https://ii41.ru/task-tracker/

`index.html` открывает существующий приватный трекер по адресу
https://ii41-focus.r1i1.chatgpt.site/ . Это переход с изменением адреса
в браузере, а не перенос приложения или его базы в GitHub Pages.

## Поведение

- Путь размещён в репозитории `IsaRoma1/IsaRoma1.github.io`, который публикует
  статические файлы через существующий GitHub Pages workflow.
- Страница не содержит задач, дневника, ключей и пользовательских данных.
- Доступ к приложению и данным продолжает проверять исходный приватный сервис.
- Параметры адреса и фрагмент `#tasks=` сохраняются для предложений GPT.
- Целевой домен фиксирован; параметр адреса не может сменить получателя перехода.
- `location.replace` исключает цикл при нажатии «Назад».
- Если автоматический переход не сработал, остаётся обычная ссылка.
- Индексация страницы запрещена метатегом robots, реферер не передаётся.

## При обновлении

Сохранять эту подпапку при публикациях главного сайта. Остальные файлы
репозитория, CNAME, .nojekyll, существующий workflow и соседние проекты не
относятся к этому разделу. При изменении скрипта нужно пересчитать SHA-256
в Content-Security-Policy по точному тексту между тегами `<script>`.

Полноценное размещение приложения с сохранением адреса `ii41.ru/task-tracker/`
потребует серверного хостинга или маршрутизации и совместимой авторизации.
Google Docs остаётся дневником, а действующая база — источником состояния задач.
